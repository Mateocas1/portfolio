Case study

ofertasSUPER

Comparador de ofertas y preciosBackend, datos y operación

Aplicación full-stack para buscar productos, comparar precios y armar una canasta local con foco en confianza del dato. Incluye APIs públicas, modelo de catálogo con Prisma/Supabase, ingesta, normalización/deduplicación, control de calidad de datos, cache/rate limiting y documentación de límites.

Problema

Comparar precios exige confianza del dato, no solo UI.

Un precio sin fuente, fecha, deduplicación ni límite visible puede confundir al usuario y debilitar el producto.

Solución Búsqueda, catálogo, APIs y canasta

Flujo público con búsqueda, detalle de producto, ofertas, canasta local y modelo de datos para sostener historial y categorías.

Tradeoffs Freshness explícito

El proyecto prioriza límites claros: no afirmar precios siempre vigentes ni ingesta activa sin evidencia fresca.

Resultado Prueba full-stack defendible

Muestra backend, datos, cache, rate limiting, admin protegido, documentación y criterio para no sobreprometer.

Límites honestos Demo y evidencia controlada

No afirmo producto cerrado, precios siempre vigentes, admin positivo productivo ni ingesta productiva activa sin smoke público reciente.

Flujo de datos

De fuente externa a búsqueda defendible.

El valor técnico está en tratar cada precio como dato con contexto: origen, validación, deduplicación, freshness y límites visibles.
