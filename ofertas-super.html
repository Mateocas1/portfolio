ofertaSUPER

Comparador de precios de supermercados argentinos

El MVP está completo y desplegado como demo pública: compara precios de 6 supermercados, empareja productos por código EAN y permite armar una canasta para comparar entre tiendas.

Volver al portfolio Demo pública Repositorio

El problema

Comparar precios exige confianza del dato, no solo interfaz.

Un precio comparado solo sirve si el producto es el mismo y el dato es consistente: la base del proyecto es la ingesta desde la API de VTEX y el emparejamiento por EAN.

Datos 6 supermercados vía API de VTEX

Carrefour, DIA, Disco, Jumbo, Vea y Más: los datos se cargan desde la API de VTEX y los productos se emparejan por código EAN.

Construcción Next.js, PostgreSQL y Redis

Next.js y TypeScript, PostgreSQL (Supabase, Prisma) y Redis para caché y rate limiting; 13 endpoints REST y panel de administración con Clerk.

Calidad CI en cada push

GitHub Actions ejecuta lint, typecheck, tests, build y Lighthouse, con alrededor de 750 pruebas automatizadas.

Operación Ingesta y backups

La ingesta corre como jobs de Docker y los backups cifrados se guardan en Cloudflare R2.

Flujo de datos

De la API de VTEX a la comparación.

Fuente API de VTEX

Datos de productos y ofertas de 6 supermercados.

Ingesta Jobs de Docker
